Firebase Production Backend Setup

Connect real Google OAuth, Phone SMS OTP, and Cloud Firestore in 3 steps

1
Create a Firebase Project

Visit console.firebase.google.com and click Add Project (e.g. pulsepm-app).

2
Enable Authentication & Firestore

In Firebase Console:
• Authentication → Sign-in method: Enable Google, Phone, and Email/Password.
• Firestore Database: Click Create database in Test Mode.

3
Paste Config into firebase-config.js

Go to Project Settings → Your apps → Web app (</>), copy the config values, and paste them into firebase-config.js.

✨ Account Linking Active: PulsePM is built to automatically link Google, Phone Number, and Email accounts into the exact same user record via Firebase linkWithCredential.
